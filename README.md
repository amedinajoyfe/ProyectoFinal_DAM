# Proyecto Final DAM - Juego de Mesa en Unity

**Autores**: Alejandro Fraile y Alejandro Medina

Este es el proyecto final del 2º curso de Desarrollo de Aplicaciones Multiplataforma (DAM). El objetivo principal es desarrollar un juego de mesa sencillo utilizando **Unity** como motor de juego y **C#** como lenguaje de programación. Adicionalmente, se implementa una base de datos básica creada en **MySQL**, a la cual se accede mediante **PHP**.

## Descripción del Juego

El juego es un simulador de un juego de mesa en el que los jugadores deben moverse por un mapa y entregar objetos en ubicaciones específicas para ganar puntos. El primer jugador en alcanzar el objetivo de puntos ganará la partida.

### Características Principales
- **Motor**: Unity
- **Lenguaje**: C#
- **Base de datos**: MySQL conectada mediante PHP
- **Arte**: La mayor parte del arte ha sido creado por los integrantes del grupo.
- **Música**: Música sin copyright obtenida de internet.
- **Botones de Debug**: Hay un botón oculto en el menú principal que permite acceder a herramientas de depuración.
